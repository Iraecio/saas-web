# Data Model: Design system

Não há persistência nova.

## Token visual

- Nome semântico
- Valor claro
- Valor escuro
- Categoria: cor, tipografia, raio, sombra, camada ou movimento
- Consumidores: utilitários globais e componentes compartilhados

## Tema

- Identificador: claro ou escuro
- Mesmo conjunto obrigatório de tokens
- Transição permitida sem alterar layout

## Componente compartilhado

- API pública existente preservada
- Variantes visuais finitas
- Estados: padrão, hover, foco, pressionado, desabilitado e carregando quando aplicável
